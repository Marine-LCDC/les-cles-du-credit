# UX Copywriting — Les Clés du Crédit

## 1. Principes de Rédaction
- Ton : Conseiller bienveillant, jamais administratif ni jugeant.
- Vouvoiement général par défaut.
- Phrases courtes (une idée par phrase).
- Boutons : Doivent impérativement commencer par un VERBE D'ACTION (ex. "Voir mon résultat", "Continuer").
- INTERDICTION STRICTE : Aucun point d'exclamation (!) dans les messages système, confirmations ou erreurs.
- Pas de jargon bancaire non expliqué (expliquer ou reformuler "reste à vivre", "HCSF", "saut de charge").

## 2. Lexique Imposé
| À ÉVITER | À UTILISER |
|---|---|
| "Renseignez vos données financières" | "Voyons ensemble votre projet" |
| "Votre dossier a été rejeté" | "Visite peu conseillée" |
| "Compatible" / "Non compatible" | Libellés de visite (cf. section 3) |
| "Vous ne pouvez pas vous permettre ce bien" | "L'écart avec votre capacité actuelle est de [montant]" |
| "Erreur : champ requis" | "Il manque encore [nom du champ]" |
| "Soumettre" | "Voir mon résultat" / "Continuer" |

## 3. Messages de Statut (badge identique agent et acquéreur)
Le libellé du badge est le même des deux côtés. Seuls les sous-textes chiffrés / pédagogiques sont réservés à l'acquéreur.
- Vert (🟢) : "Visite recommandée"
- Orange (🟠) : "Visite possible" — acquéreur : sous-texte pédagogique selon les indicateurs (ex. financement complémentaire, analyse bancaire).
- Rouge (🔴) : "Visite peu conseillée" — acquéreur : sous-texte "Écart de [montant] par rapport à votre capacité estimée." (Ne jamais sous-entendre une faute du client).
